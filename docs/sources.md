# 来源与核实规范

适用于所有关键事实：价格、配置、权益、政策、安全、技术参数、法规、上市/交付及销量。

1. 优先厂家官网、官方配置表、工信部、监管机构；配置参数先交叉查汽车之家，再查懂车帝和主流媒体。销量先汽车之家分类榜，再查懂车帝，标记零售/批发、月份、车系/车型。
2. 同一关键结论至少三条独立信息源。转载同一新闻稿、同一测试的剪辑及搬运算同一 origin_group；三篇同源报道不能升级 verified。
3. 每条事实记录 source_ids、适用年款/配置/地区、核实时间与验证状态。来源登记作者/机构、标题、原始 URL、发布时间、访问时间、摘录定位及独立来源组。
4. official_confirmation 表示官方是否确认，verification 表示交叉验证状态，两者分开。官方单源仍可注明“官方已公布，尚未完成三源核实”。
5. verification：pending（零来源）、single_source（一独立来源）、partial（两独立来源）、verified（三个及以上独立来源且口径一致）、conflicting（有冲突）、expired（过有效期）。冲突和失效优先于数量，缺失发布时间填 null。
6. 冲突逐项保留双方表述、版本、时间及证据。不要投票；不能解释的差异阻止确定性推荐。
7. 公开事实、厂家承诺、媒体实测、车主经历、实战口述、分析推断、建议分别标注。单条投诉不能推导故障率；未交付车型没有长期车主可靠性结论。
8. 价格/权益发布当天复核；已失效优惠只保留历史用途。配置及软件功能发布前检查当前年款、批次、地区、软件版本和开通范围；未来 OTA 不当作现成功能。
9. 图片、直播截图记录原链接、时间点、权利/使用授权状态；未确认可用的素材不进入公开发布稿。只存必要摘录，不复制整篇付费或受限内容。
10. 无法联网或来源不可读：交付框架、已知限制与待核实清单，不宣称完成当前事实核验。
