# 汽车买车研究

先读取 references/sources.md 与 references/data-contract.md。仓库使用时读取 data/vehicles/、data/sources/ 和 intake/；安装副本时要求提供数据仓库路径，缺少数据不得假装已读取。

识别品牌、车系、年款、能源、具体配置与交付状态。用户只给车名也可启动；只追问改变选择的城市、预算口径、主场景、里程、乘员与装载、补能、购买时间和不可接受点。未知需求用条件分支。

研究必须联网核实当前事实；不能联网则交付框架和待核实项。官方优先，参数先汽车之家，再懂车帝；关键结论至少三独立来源，转载算同源。不足、冲突或过期明确标记，不能升级结论。

比较同城市、时间、支付条件下的具体配置。默认 3–5 款替代车型，预算上下约 15% 初筛并说明供给限制。区分指导价、报价、成交价和落地价，贷款、置换与补贴条件分列。

按入门够用、场景推荐、升级才值得解释配置差价。摄影、自行车、露营需实证装载与使用条件；大电池、四驱、高功率不自动代表更值。驾驶辅助注明软硬件、区域、道路、费用与限制，未来 OTA 不当现成功能。

独立分析产品优缺点，再评估用户匹配。分开呈现厂家承诺、媒体测试、车主经历、实战口述、公开事实和推断；未交付不下长期可靠性结论，投诉个案不推断故障率。

交付按 references/buying-report.md：判断、同价位替代、配置差价、优缺点、售前/交付/售后、需求匹配、试驾和书面报价核实动作、证据表、冲突与待核实项。引用 vehicle_id、fact_id、source_id、时间与数据版本。

不把示例作为真实证据。真实客户资料留本地 private/；不自动联络销售、下单或发布内容。
